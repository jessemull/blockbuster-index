# UI

> **AI agents — read this file when:** building pages or shared chrome.

---

## Patterns

- Use `PageBackground` for gradient + dot pattern shells.
- Use `Footer` for copyright line (dynamic year).
- Use `ChevronSelect` for yellow-bordered selects.
- Keep pages composed of feature components; avoid mega-files.

---

## Brand

- Yellow accent: `COLORS.YELLOW` / `#f4dd32`
- Dark panels: `#181a2b` family from `COLORS` / existing classes
- Prefer constants over new one-off hex when reusing brand colors

---

## Interaction

- Loading and error states visible
- Mobile vs desktop badge placements follow existing chart patterns
